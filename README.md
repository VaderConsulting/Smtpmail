# Smtpmail

VB6 message sender (`SendMessage.exe`): UI/batch helper that sends either SMTP mail or NET SEND (`NetMessageBufferSend`), including anonymous SMTP and a file= batch format for bulk lines. Open `Project1.vbp` in the VB6 IDE.

**Source last updated:** 2000-06-01 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe
